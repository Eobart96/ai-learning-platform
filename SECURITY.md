# Security Policy

## Секреты

Никогда не добавлять в GitHub:

- OpenAI API key;
- JWT secret;
- пароль базы данных;
- приватные токены;
- `.env`.

## Пользовательские данные

- хранить только необходимые данные;
- хешировать пароли;
- ограничивать доступ к данным пользователя;
- не отправлять лишние персональные данные в AI;
- добавить возможность удаления аккаунта.

## Сообщение об уязвимости

Не публиковать критическую уязвимость в открытом issue. Использовать приватный канал связи владельца проекта.
