# Описание для портфолио

## Название

AI Learning Platform

## Краткое описание

Универсальная образовательная платформа на основе LLM, которая проводит адаптивные уроки, проверяет ответы, анализирует ошибки, создает домашние задания и отслеживает прогресс пользователя.

Первым реализованным курсом является словацкий язык для русскоговорящих пользователей.

## Проблема

Обычные учебные приложения дают одинаковый материал всем пользователям и плохо учитывают повторяющиеся ошибки конкретного ученика.

## Решение

Платформа сохраняет учебную историю, определяет слабые темы и адаптирует задания на основе реальных результатов пользователя.
