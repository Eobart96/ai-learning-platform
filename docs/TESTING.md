# План тестирования

## Backend

- unit-тесты сервисов;
- API-тесты;
- тесты авторизации;
- тесты базы данных;
- тесты миграций;
- тесты обработки ошибок.

## AI

- корректный JSON;
- правильная классификация ошибок;
- отсутствие выдуманных фактов;
- соблюдение языка ответа;
- стабильность формата;
- тесты на типовые ошибки ученика.

## Frontend

- регистрация;
- вход;
- загрузка курса;
- прохождение урока;
- отправка ответа;
- отображение исправления;
- мобильная версия.

## Минимальный набор перед релизом

- пользователь может зарегистрироваться;
- пользователь может войти;
- курс открывается;
- урок открывается;
- ответ сохраняется;
- AI-результат валиден;
- прогресс обновляется;
- домашнее задание создается;
- повторный вход не теряет данные.
