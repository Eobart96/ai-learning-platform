# ADR 0001: канонический интерактивный курс и граница persistence

- Статус: принято
- Дата: 2026-08-26

## Контекст

В проекте существовали два независимых курса: классический server-backed
контур на YAML и новый интерактивный Slovak A1 с типизированным frontend-
контентом и отдельными таблицами `module1_beta_*`. Одновременное подключение
обоих интерфейсов делало источник истины неоднозначным, но физическое удаление
старых SQLite-таблиц могло повредить существующую локальную базу.

## Решение

1. Единственная рабочая точка входа — `/`, интерактивный Slovak A1.
2. Канонический источник структуры и содержания курса — типизированные файлы
   `frontend/app/data/`, собираемые `a1Course.ts`.
3. Универсальный контракт, операции и проверки отделены в `courseTypes.ts`,
   `courseEngine.ts` и `courseValidation.ts`. React-компонент не содержит
   списков тем, специфичных для Module 1.
4. Backend и SQLite являются источником сохранённого состояния, созданных
   материалов, словаря и повторений интерактивного курса.
5. Отключённый frontend, классический backend и исторические отчёты вынесены в
   локальный восстановимый `del/` и не входят в public-ready дерево.
6. Активные SQLAlchemy-модели ограничены `module1_beta_*`. Старые таблицы в
   существующей SQLite физически не удаляются и не изменяются.
7. Новый и классический stores не синхронизируются. Стабильные slug, activity
   ID и поля состояния сохраняются как контракт пользовательских данных.

## Последствия

- Новый модуль добавляется данными и при необходимости небольшой адаптацией
  сборщика, без копирования экрана Module 1.
- Ошибки порядка, повторные идентификаторы, неверные группировки и битые связи
  CEFR обнаруживаются при загрузке/проверке курса.
- Имена компонентов, типов и API приведены к универсальному `Course*`.
  Прежние физические имена таблиц `module1_beta_*` сохраняются только ради
  совместимости существующей локальной базы.
- Физическая очистка старых SQLite-таблиц или переименование persistence-
  контракта должно оформляться отдельным ADR, backup и планом миграции.
