# Архитектура системы

## Общая схема

```text
Web / Telegram
      |
      v
Frontend
      |
      v
FastAPI Backend
  |       |       |
  v       v       v
Database  OpenAI  Course Content
```

## Компоненты

### Frontend

Отвечает за:

- интерфейс;
- авторизацию;
- отображение курсов;
- уроки;
- чат;
- прогресс;
- домашние задания;
- словарь;
- дневник.

### Backend

Отвечает за:

- бизнес-логику;
- пользователей;
- доступ к данным;
- обработку уроков;
- вызовы AI;
- анализ ошибок;
- генерацию заданий;
- рекомендации.

### Database

Хранит:

- пользователей;
- курсы;
- уроки;
- упражнения;
- ответы;
- ошибки;
- домашние задания;
- словарь;
- дневник;
- статистику.

### AI layer

Содержит:

- системные промпты;
- правила проверки;
- генерацию объяснений;
- классификацию ошибок;
- генерацию упражнений;
- рекомендации следующего шага.

### Course engine

Курсы должны быть отделены от основной логики. Курс описывается данными, а не жестко прописанным кодом.

## Архитектурные принципы

- один backend для всех клиентов;
- курс как конфигурация;
- структурированные AI-ответы;
- минимальное доверие к свободному тексту AI;
- валидация через Pydantic;
- хранение учебных событий;
- постепенное усложнение;
- монолит для MVP;
- микросервисы только при реальной необходимости.
