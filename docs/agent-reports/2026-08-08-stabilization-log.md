Локальный `backend/.venv` использует Python 3.13 и не может импортировать `pydantic_core._pydantic_core`; из-за этого FastAPI/Pydantic не загружаются и pytest не начинает сбор тестов.

## Журнал решений

### 2026-08-08 — порядок работ: окружение → проверки → diary

Выбран порядок «сначала окружение и тесты, затем extraction diary».

**Почему:** router extraction без работоспособной проверки может незаметно изменить API-поведение. `diary` выбран первым предметным доменом, так как он цельный, а перенос read-only маршрутов позволит минимизировать риск перед переносом AI-зависимой записи.

### 2026-08-08 — очистка `PYTHONPATH` для backend-команд Hermes

Для команд проверки выбран `env -u PYTHONPATH`.

**Почему:** глобальный `PYTHONPATH` Hermes направлял импорты в собственное окружение агента, что маскировало содержимое нового `.venv` и давало ложный сбой `pydantic_core`. Очистка переменной ограничена процессом конкретной команды и не является изменением конфигурации приложения.
