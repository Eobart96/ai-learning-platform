# Product Requirements Document

## Продукт

AI Learning Platform

## Целевая аудитория

- самостоятельные ученики;
- абитуриенты;
- изучающие языки;
- начинающие программисты;
- пользователи, которым нужен персональный темп.

## Основная проблема

Одинаковые уроки для всех не учитывают личные ошибки и скорость обучения.

## Ценность

Платформа создает персональный цикл:

```text
урок -> ответ -> проверка -> ошибка -> повторение -> прогресс
```

## Основные пользовательские истории

### Ученик

- Я хочу выбрать курс.
- Я хочу продолжить с последнего урока.
- Я хочу получить объяснение ошибки.
- Я хочу увидеть слабые темы.
- Я хочу получить домашнее задание.
- Я хочу повторить забытые слова.
- Я хочу вести дневник на изучаемом языке.

## Метрики MVP

- завершенные уроки;
- число активных дней;
- процент выполненных домашних заданий;
- изменение доли повторяющихся ошибок;
- количество повторенных слов;
- возвращаемость пользователей.

## Ограничения MVP

- один основной курс;
- один тип аккаунта;
- без платежей;
- без социальной сети;
- без собственного мобильного приложения.
