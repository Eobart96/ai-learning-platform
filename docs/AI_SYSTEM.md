# AI-система

## Основные задачи AI

- объяснять материал;
- вести диалог;
- проверять ответы;
- классифицировать ошибки;
- создавать упражнения;
- адаптировать сложность;
- генерировать домашние задания;
- составлять рекомендации;
- исправлять дневниковые записи.

## Главное правило

AI должен возвращать структурированные данные, когда результат используется приложением.

## Формат проверки ответа

```json
{
  "is_correct": false,
  "score": 70,
  "corrected_answer": "Mám päť jabĺk.",
  "mistakes": [
    {
      "category": "noun_after_number",
      "original": "jablk",
      "corrected": "jabĺk",
      "explanation": "Краткое объяснение."
    }
  ],
  "short_feedback": "Хорошая попытка.",
  "next_task": "Составь новое предложение."
}
```

## Версионирование промптов

Каждый системный промпт должен иметь версию:

```text
slovak_tutor_v1
slovak_tutor_v2
answer_checker_v1
homework_generator_v1
```

Версия должна сохраняться в журнале AI-взаимодействий.

## Безопасность

Нельзя передавать в модель:

- пароли;
- секретные ключи;
- приватные токены;
- лишние персональные данные.

## Контроль качества

- Pydantic-валидация;
- повторный запрос при неверном JSON;
- ограничения длины;
- журнал ошибок;
- тестовые примеры;
- ручная проверка важных промптов.
