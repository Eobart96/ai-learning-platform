# Отчёт о реализации локального MVP

Последнее обновление: 2026-08-14.

## Текущий итог

- FastAPI и SQLite обеспечивают полный локальный учебный цикл одного пользователя;
- курс Slovak A1 содержит 7 модулей, 31 тему, теорию, упражнения и диалоги;
- основной UI запускается через Next.js на порту 3000;
- все рабочие экраны реализованы нативно в React; legacy-ассеты сохранены,
  но не подключаются к рабочему интерфейсу;
- ошибки из учебных источников учитываются отдельно для каждого курса,
  связаны с упражнениями и исчезают из активного списка после явного
  подтверждения исправления;
- отработка ошибки создаёт отдельный диалог `Исправления ошибок`;
- ожидание AI не блокирует остальные действия интерфейса;
- доступны модульные тесты, словарь/Anki, дневник и домашние задания;
- добавлен отдельный подготовительный курс математики с локальной проверкой
  числовых ответов;
- TypeScript strict-проверка проходит для текущих frontend-изменений;
- добавлен раздел «Чтение»: AI создаёт текст по текущей теме и завершённой
  теории курса, затем проверяет пересказ ученика;
- добавлена единая словацкая экранная клавиатура с Shift/Caps Lock во всех
  текстовых полях, включая чат разбора ошибок и тесты;
- целевой API-набор проходит: 20 тестов, 1 внешнее предупреждение Starlette;
- полный backend-набор содержит 52 теста, но в этой Windows-сессии его запуск
  не вернул финальный статус до завершения процесса, поэтому полный результат
  не подтверждён.

Следующий технический этап — диагностировать production build Next.js: повторная
локальная попытка 2026-08-02 не завершилась за 240 секунд и не вывела ошибки;

## Цель

Создать минимальную основу backend для локального MVP без регистрации, JWT,
PostgreSQL, frontend и вызовов OpenAI.

## Что реализовано

### Приложение

- FastAPI-приложение в backend/app/main.py;
- GET /health для проверки доступности процесса;
- GET /api/v1/courses для проверки загруженных курсов;
- startup-инициализация базы и импорт YAML-курса.

### Конфигурация

backend/app/config.py использует pydantic-settings. Поддерживаются:

- DATABASE_URL;
- COURSE_PATH;
- .env в корне запуска.

По умолчанию создается SQLite-файл backend/data/app.db.

### База данных

backend/app/database.py создает SQLAlchemy engine и сессию. При SQLite
каталог базы создается автоматически.

В backend/app/models.py добавлены модели:

- Course;
- Module;
- Lesson;
- Exercise;
- LessonAttempt;
- UserAnswer;
- Mistake.

Связь контента курса: Course -> Module -> Lesson -> Exercise.
Пользовательские сущности пока не связаны с User, потому что локальный MVP
работает без регистрации.

### Загрузка курса

backend/app/course_loader.py читает YAML с UTF-8, создает курс, модули,
уроки и упражнения. Импорт идемпотентный: повторный startup не создает курс
с тем же slug повторно.

## Поток запуска

1. Импортируется конфигурация.
2. Создается каталог SQLite-базы.
3. FastAPI startup создает таблицы через Base.metadata.create_all.
4. YAML-курс загружается в SQLite.
5. API начинает отдавать health-check и список курсов.

Добавлен автоматический тест `test_all_a1_lessons_have_substantive_theory`: он проверяет наличие всех 31 уроков и минимальный объем теории у каждого урока. Это защищает от возврата к пустым или слишком коротким заглушкам.

### Тестовый переход между темами

В центральную панель добавлена кнопка `Закончить тему (тест)`. Она не создаёт отдельную логику завершения: интерфейс отправляет серверу команду `сохрани прогресс`, после чего используется штатный обработчик диалога. Сервер создаёт завершённую попытку, рассчитывает следующую незавершённую тему и обновляет сессию. Это позволяет быстро проверить roadmap-переход без ручного решения упражнений.

### Теория в главном чате

Теперь теория является частью живого диалога, а не только боковой карточки. Если новая сессия не содержит сообщений, frontend автоматически отправляет `Начнем урок`. Сервер передает AI-преподавателю полную теорию текущей темы, историю сообщений, позицию в roadmap, ошибки и упражнения.

В фазе `theory` AI обязан объяснять правила по шагам, разбирать вопросы и утверждения ученика в рамках текущей темы, приводить словацкие примеры с переводом и не переходить к упражнению преждевременно. Команда `готов к упражнению` переводит сессию в фазу `practice`. Завершение темы и сохранение прогресса остаются серверными операциями.

### Подключение пользовательских MD-источников

Актуальные файлы `Student_Profile.md`, `Learning_Roadmap.md` и `Teaching_Method.md` перенесены в `course-content/slovak-a1/learning/` как `student_profile.md`, `learning_roadmap.md` и `teaching_method.md`. Экранированные символы исходного текста нормализованы в обычный Markdown, чтобы заголовки и списки корректно попадали в prompt. AI-преподаватель читает эти файлы через `build_tutor_context` при каждом обращении, поэтому изменения профиля, roadmap или методики влияют на новые ответы без изменения кода.

### Отображение учебного текста

Ранее чат экранировал весь ответ AI как обычный текст, поэтому пользователь видел `###`, `**` и разделители таблиц. Добавлен безопасный Markdown-рендерер во frontend: он поддерживает заголовки, абзацы, списки, жирное/курсивное выделение, inline-код и таблицы. HTML из ответа предварительно экранируется, поэтому форматирование не открывает возможность вставки произвольной разметки. Версия frontend обновлена до cache-buster `v8`.

## Работа за 2026-07-21: практический контент и учебный интерфейс

### Практика A1

Добавлен файл `course-content/slovak-a1/practice.yaml`. Для каждой из 31 тем A1 теперь есть два переводческих упражнения и один диалоговый сценарий. Сценарии покрывают знакомство, магазин, кафе, транспорт, работу, семью, хобби и бытовые ситуации.

`backend/app/course_loader.py` загружает этот слой отдельно от теории и добавляет только отсутствующие упражнения. Сравнение выполняется по теме, типу, вопросу, инструкции и правильному ответу, поэтому повторный запуск backend не создает дубли.

В фазе `practice` AI получает тип задания и инструкцию сценария. Сервер по-прежнему остается источником истины для текущей темы, фазы и сохранения прогресса.

### Синхронизация roadmap и живого чата

Добавлен endpoint `POST /api/v1/dialogue/sessions/{id}/select-lesson`. При выборе темы в roadmap сервер переключает `current_lesson_id`, сбрасывает фазу в `theory` и возвращает выбранный урок. Frontend после выбора темы автоматически запрашивает подробную теорию в чате. Это устраняет ошибку, при которой карточка показывала «Числа», а AI продолжал работать со старой темой.

В шапке чата добавлена кнопка `Показать теорию в чате`. Боковая карточка текущей темы сохраняет краткий доступный материал, а расширенное объяснение, вопросы и практика проходят в основном диалоге.

### Обновление frontend

Главный режим теперь содержит чат, roadmap, текущую тему и сводку. В шапке доступны отдельные режимы упражнений, слов, дневника и домашних заданий. Рабочие области упражнений, дневника и домашних заданий увеличены: добавлены более крупные карточки, поля ввода, отступы и адаптивная раскладка.

В чат, упражнения и дневник добавлена экранная словацкая клавиатура с диакритическими буквами и сочетаниями `ch`, `dz`, `dž`. В чате Enter отправляет сообщение, Shift+Enter создает перенос строки, пользовательское сообщение появляется сразу, а во время ответа показывается индикатор ожидания.
