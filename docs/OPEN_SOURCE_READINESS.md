# Open-source readiness

Статус: подготовка продолжается. Последнее подтверждённое обновление: 2026-08-09.

AI Learning Platform — экспериментальный **vibe-coded** проект: изменения
разрабатываются итеративно с AI-инструментами, но публичные контракты, тесты и
документация должны проверяться человеком. Это не медицинский, экзаменационный
или коммерческий образовательный сервис.

## Подтверждённое состояние

- один репозиторий: Next.js frontend, FastAPI backend, SQLite для одного
  локального пользователя;
- основной курс — Slovak A1; также есть модуль подготовки по математике;
- AI-разбор ошибки изолирован от учебного прогресса и не создаёт учебную сессию;
- сгенерированные упражнения сохраняются отдельным личным списком темы;
- локально подтверждены: `59 passed, 1 warning` backend-тестов, TypeScript и
  production build frontend;
- есть MIT `LICENSE`, README, SECURITY, CONTRIBUTING, Code of Conduct, PR и
  issue templates, а также CI для Python 3.12 и Node 22;
- публикация, настройка видимости GitHub, release, commit и push не выполнялись
  в рамках этой подготовки.

## Аудит публичной безопасности от 2026-08-09

Проверены правила игнорирования для `.env`, SQLite-базы, Python venv,
`node_modules`, приватного профиля `.ai/private/` и `_backups/`: все они
игнорируются. По именам tracked-файлов не найдено путей, похожих на ключи,
сертификаты, credentials или базы данных.

Ограничения аудита:

- содержимое `.env`, баз и приватных профилей намеренно не читалось;
- перед первой публикацией нужно вручную проверить полный staged diff;
- `SECURITY.md` пока не содержит согласованного отдельного приватного канала
  disclosure; не публикуйте уязвимости в issue.
