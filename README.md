# AI Learning Platform

Универсальная образовательная платформа с AI-преподавателем, адаптивными уроками, проверкой заданий, анализом ошибок, домашними заданиями и отслеживанием прогресса.

> **Экспериментальный vibe-coded проект.** Платформа развивается быстрыми
> итерациями вместе с AI-инструментами и ручной проверкой результатов. Это не
> готовый коммерческий сервис: перед использованием в реальном обучении
> проверяйте AI-ответы и не добавляйте в локальную установку чувствительные данные.

Основной курс проекта — **словацкий язык для русскоговорящих пользователей**.
Также доступен отдельный подготовительный модуль по математике.

## Основные возможности

- полный курс Slovak A1: 7 модулей и 31 тема;
- подготовительный курс математики: числа, дроби, степени, корни и линейные уравнения;
- точная локальная проверка числовых ответов по математике — без вызова AI;
- AI-уроки и диалоги с сохраняемой историей;
- автоматическая проверка ответов;
- отдельный журнал ошибок для каждого курса с целевой отработкой в изолированном AI-чате и подтверждением исправления;
- генерация дополнительных упражнений по выбранной теме с сохранением в личном списке;
- хранение прогресса в локальной SQLite;
- домашние задания и модульные итоговые тесты;
- персональный словарь, экспорт для Anki и интервальное повторение;
- AI-дневник и статистика слабых тем;
- светлая и графитовая тёмная тема.

## MVP

Пользователь должен иметь возможность:

1. Открыть курс словацкого языка.
2. Открыть урок.
3. Ответить на упражнение.
4. Получить исправление и объяснение.
5. Сохранить попытку и ошибку.
6. Продолжить обучение на этом же локальном устройстве.

Регистрация, JWT и многопользовательский режим относятся к следующим этапам после стабилизации локального учебного цикла.

## Быстрый старт

### Windows — автоматическая установка

1. Установи Python 3.12 или новее и Node.js 20 LTS или новее с официальных сайтов. В установщиках включи добавление в `PATH`.
2. Склонируй репозиторий или распакуй архив.
3. Проверь в PowerShell: `python --version` и `node --version`.
4. Запусти `install.cmd` из корня проекта: он создаст `backend/.venv`, установит Python-зависимости и выполнит `npm install` в `frontend`.
5. После завершения запусти `start.cmd`. Backend будет доступен на `http://127.0.0.1:8000/`, frontend — на `http://127.0.0.1:3000/`.

Скрипт создаёт `backend/.venv`, устанавливает Python-зависимости и пакеты
Next.js, затем создаёт `.env` из `.env.example`, если `.env` ещё не существует.
Повторный запуск безопасен: существующее окружение переиспользуется, а `.env`
не перезаписывается.

Если окружение перенесено с другого компьютера или ссылается на удалённую
версию Python, `install.cmd` автоматически пересоздаст его.

```bash
cd backend
python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
uvicorn app.main:app --reload
```

После запуска доступны:

- `GET http://127.0.0.1:8000/health` — проверка работоспособности;
- `http://127.0.0.1:3000/` — основной Next.js frontend;
- `http://127.0.0.1:8000/ui/` — совместимый статический UI FastAPI (для локальной диагностики);
- `GET http://127.0.0.1:8000/api/v1/courses` — загруженные курсы;
- `GET http://127.0.0.1:8000/api/v1/lessons/1` — конкретный урок;
- `POST http://127.0.0.1:8000/api/v1/lessons/1/answer` — ответ ученика;
- `POST http://127.0.0.1:8000/api/v1/lessons/1/complete` — завершение урока;
- `GET http://127.0.0.1:8000/api/v1/progress` — общий прогресс;
- `GET http://127.0.0.1:8000/api/v1/progress/mistakes?course_slug=slovak-a1` — повторяющиеся ошибки словацкого курса;
- `POST http://127.0.0.1:8000/api/v1/homework/generate` — создать домашнее задание;
- `GET http://127.0.0.1:8000/api/v1/homework` — список домашних заданий;
- `POST http://127.0.0.1:8000/api/v1/dialogue/sessions` — начать учебный диалог;
- `GET http://127.0.0.1:8000/api/v1/dialogue/sessions/{id}` — восстановить диалог;
- `POST http://127.0.0.1:8000/api/v1/dialogue/sessions/{id}/messages` — продолжить диалог;
- `POST http://127.0.0.1:8000/api/v1/dialogue/sessions/{id}/select-lesson` — переключить тему текущей учебной сессии;
- `POST http://127.0.0.1:8000/api/v1/tutor/message` — сообщение AI-преподавателю;
- `http://127.0.0.1:8000/docs` — интерактивная документация API.

SQLite-база создается автоматически в `backend/data/app.db`. Путь к базе и YAML-курсу можно изменить переменными `DATABASE_URL` и `COURSE_PATH`.

### Режимы AI-преподавателя

По умолчанию используется `TUTOR_PROVIDER=codex`. Backend запускает локальный
`codex.cmd` через авторизацию Codex/ChatGPT-подписки в read-only режиме.

В интерфейсе отображается состояние подключения. Кнопка `Подключить Codex`
запускает официальный вход, после которого Codex используется как локальный
AI-агент преподавателя.
Перед этим один раз выполни в PowerShell:

```powershell
cmd.exe /d /s /c "codex.cmd login"
```

Для API-режима в `.env` укажи:

```text
TUTOR_PROVIDER=openai
OPENAI_API_KEY=your_api_key
```

Оба режима используют профиль, roadmap и методику из
`course-content/slovak-a1/learning/`. Публичный `student_profile.md` —
обезличенный пример. Для локального персонального профиля создай
`.ai/private/student_profile.local.md`: он имеет приоритет и игнорируется Git.

Проверка тестов:

```bash
cd backend
pytest
```

Текущий подтверждённый набор (2026-08-12): 62 backend-теста и TypeScript
strict-проверка. Production build frontend пока не подтверждён: `next build`
зависает после стартовой строки и требует отдельной диагностики.

## Аналитика обучения

Ошибки словацкого курса из упражнений, домашних заданий, дневника, живого
диалога и модульных тестов собираются в его разделе `Ошибки`. У математики
свой изолированный список: записи и действия над ошибками всегда ограничены
`course_slug` и не пересекают словацкий курс. Для каждой записи сохраняются
исходный ответ, исправление, объяснение, тема и источник. Выбранную ошибку можно разобрать в отдельном изолированном AI-чате: он не
создаёт учебную сессию и не меняет прогресс, уроки, дневник или домашние
задания. Подтверждённое исправление удаляет запись из активного списка и
учитывается в сводке. Кнопка «Исправить всё» после подтверждения закрывает
только активные ошибки текущего курса.

AI получает теорию текущего урока как жёсткую границу и не должен использовать
непройденную грамматику. Если заданию нужна новая лексика, агент предоставляет
готовый банк слов с родом и русским переводом.

## Статус

Проект находится на этапе стабилизации локального учебного MVP. Основной UI
работает через Next.js и нативные React-компоненты: шапка, учебный чат,
roadmap, упражнения, тесты, ошибки, словарь, дневник и домашние задания.
Legacy-ассеты в `frontend/public/legacy` сохранены как неактивный резервный
путь и не подключаются к рабочему интерфейсу.

Перед публикацией в open source см. [план готовности](docs/OPEN_SOURCE_READINESS.md).

## Разработка с Codex

Для работы с Codex используется папка `.ai/`:

- `PROJECT_CONTEXT.md` — цель, стек и ограничения проекта;
- `CURRENT_STATE.md` — фактическое состояние реализации;
- `NEXT_TASK.md` — одна следующая задача;
- `CONVENTIONS.md` — правила кода и разработки;
- `DECISIONS.md` — принятые архитектурные решения;
- `CODEX_INSTRUCTIONS.md` — порядок работы агента.

Начальный запрос для Codex:

```text
Прочитай .ai/CODEX_INSTRUCTIONS.md и все указанные в нем файлы. Затем выполни задачу из .ai/NEXT_TASK.md. Не добавляй функциональность вне текущего этапа. После реализации запусти проверки и обнови CURRENT_STATE.md и NEXT_TASK.md.
```

> Для раннего MVP регистрация не требуется. Сначала реализуется полный учебный цикл для одного локального пользователя.

## Запуск в Windows

После установки запусти `start.cmd`. Backend и frontend откроются в отдельных
окнах; не закрывай их, пока пользуешься приложением. Backend использует локальное виртуальное окружение
`backend/.venv`, а Next.js UI открывается по адресу `http://127.0.0.1:3000/`.
