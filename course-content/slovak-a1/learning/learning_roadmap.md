# Slovak Learning Roadmap

### Module 1 — Foundations

- Slovak alphabet and pronunciation
- Greetings
- Introducing yourself
- Numbers
- Days and months
- Personal pronouns
- Verb byť

### Module 2 — Nouns

- Masculine
- Feminine
- Neuter
- Singular and plural
- Basic noun endings

### Module 3 — Adjectives

- aký / aká / aké / akí
- ten / tá / to / tí
- môj / moja / moje

### Module 4 — Cases

- Nominative
- Accusative
- Basic prepositions

### Module 5 — Verbs

- Present tense
- Common irregular verbs
- Reflexive verbs: sa, si

### Module 6 — Everyday Communication

- Family
- Home
- Shopping
- Food
- Restaurant
- Transport
- Work
- Hobbies

### Module 7 — Past Tense

- Regular verbs
- Irregular verbs
- Talking about yesterday
