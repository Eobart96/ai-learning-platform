# История изменений

## 2026-08-09

- Обновлена open-source документация: проект описан как экспериментальный
  vibe-coded проект с обязательной ручной проверкой AI-результатов.
- Проведён audit `.gitignore` для секретов, базы, виртуальных окружений,
  зависимостей, приватных профилей и backup-артефактов; правила подтвердили
  игнорирование всех проверенных локальных путей.
- Добавлены Code of Conduct, шаблоны issue и pull request, а также план
  безопасного разбиения текущего рабочего дерева на будущие Git-коммиты.
- `docs/OPEN_SOURCE_READINESS.md` обновлён фактическими результатами: 59
  backend-тестов, TypeScript и production build frontend проходят локально.

## 2026-08-02

- Начат этап подготовки к open source: добавлен план
  `docs/OPEN_SOURCE_READINESS.md`; публикация и GitHub-операции не выполнялись.
- Персональный словацкий профиль перенесён в игнорируемый локальный файл
  `.ai/private/student_profile.local.md`; публичный курс использует
  обезличенный пример и сохраняет локальный override.
- `_backups/` и `head_main.py` защищены `.gitignore` от случайного добавления.
- Проверены публичный шаблон профиля и локальный override; backend-набор вырос
  до 46 тестов.
- Добавлен локальный GitHub Actions workflow для backend-тестов, TypeScript и
  production-сборки frontend; он не запускался удалённо, потому что публикации
  в GitHub ещё не было.
- Начат модульный рефакторинг backend: Codex status/login и tutor message
  перенесены в `app.routers.tutor`, схемы и выбор провайдера вынесены из
  `main.py`; внешний API сохранён, 46 тестов проходят.
- Каталог курсов и versioned study-roadmap перенесены в
  `app.routers.courses`; добавлены Pydantic-контракты ответов. URL и JSON
  сохранены, 46 backend-тестов и реальный локальный HTTP API проверены.
- Получение урока и генератор числовых задач перенесены в
  `app.routers.practice`; сохранены URL, JSON-ответы и исключение
  сгенерированных задач из стартового списка темы. Проверены 46 backend-тестов
  и локальный HTTP API.
- AI-проверка ответа урока и сохранение попытки вынесены в
  `app.services.lesson_answers`; endpoint, транзакция ошибок и новых слов
  сохранены. Проверены 46 backend-тестов и локальный HTTP API.
- Общие операции ошибок, словаря и стартовой дедупликации перенесены в
  `app.services.learning_state`; все учебные домены используют одну реализацию.
  Проверены 46 backend-тестов и перезапуск локального API.
- Endpoint отправки ответа урока и его Pydantic-контракты перенесены в
  `app.routers.practice`; числовая проверка вынесена в
  `app.services.answer_checking`. URL и JSON сохранены, проверены 46 тестов и
  локальный HTTP API.
- Read-only сводка прогресса перенесена в `app.routers.progress` с отдельным
  Pydantic-контрактом. URL и шесть полей JSON сохранены, проверены 46 тестов и
  локальный HTTP API.
- Read-only список активных ошибок перенесён в `app.routers.progress`; фильтр
  `course_slug` и JSON сохранены. Проверены 46 тестов и локальный HTTP API.
- Действия «отработать» и «исправить» для ошибок перенесены в
  `app.routers.progress`; SQLite-транзакции и JSON сохранены. Проверены 46
  backend-тестов.
- Все общие vocabulary-маршруты перенесены в `app.routers.vocabulary`; Pydantic-
  контракты и builder JSON-ответа вынесены из `main.py`. Сохранены URL,
  транзакции SQLite и интервалы повторения; проверены 46 backend-тестов.
- Добавлены API-регрессии vocabulary-router: выбор следующего сохранённого
  слова и ответы `404` для отсутствующих карточек. Полный набор вырос до 47
  backend-тестов.
- Выполнен checkpoint: подтверждены 47 backend-тестов и TypeScript; повторный
  production build Next.js не завершился за 240 секунд и отмечен как
  незавершённая проверка для следующего этапа.

- Добавлен курс «Математика · подготовка к экзамену» с 4 модулями, 8 темами и 24 задачами.
- Добавлен нативный раздел «Математика» с изолированным roadmap и завершением тем.
- Числовые ответы проверяются локально: поддерживаются целые числа, дроби и десятичная запись с точкой или запятой.
- Тесты диалогов изолированы от реального Codex-провайдера офлайн-подменой.
- Проверены: 40 backend-тестов и TypeScript strict-проверка.
- Шапка и навигация разделены по предметам: словацкий интерфейс больше не
  отображается внутри математического модуля.
- В математике добавлены отдельные страницы итоговых тестов и ошибок;
  проверки используют точное сравнение чисел, дробей и десятичных значений.
- Математический roadmap на август 2026 — июнь 2027 встроен в левую панель
  «Курс» по модели словацкого roadmap: текущий этап раскрывает уроки,
  будущие этапы остаются закрытыми.
- Для 8 текущих тем математики добавлен бесконечный генератор проверяемых
  числовых задач. Новые варианты сохраняются для проверки и ошибок, но не
  попадают в постоянный стартовый список упражнений темы.
- В математике появился отдельный раздел «Практика»: выбери любую тему и
  переходи к следующему сгенерированному заданию без ограничения.
