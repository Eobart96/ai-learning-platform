- [x] Один канонический интерактивный Slovak A1 на `/`.

- [x] SQLite-состояние Module 1, практика, чтение, словарь и домашние задания.

## Ближайшие задачи

1. Отозвать прежний provider credential, след которого подтверждён в
   Git-истории, и записать только факт отзыва без значения секрета.
2. Подготовить отдельное обновление зависимостей: `npm audit` сообщает 6 high
   advisories, а полный автоматический fix предлагает breaking-переход на
   Next.js 16.
3. Провести ручную приёмку `/` с реальным AI-provider в светлой/тёмной теме и
   узком окне.
4. Проверить качество и глубину Modules 2–8 относительно эталонного Module 1.
