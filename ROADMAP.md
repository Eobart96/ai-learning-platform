# Roadmap

## Текущая позиция проекта

**Сейчас:** Этап 4 и перенос экранов в React завершены для локального MVP.
Next.js является основной точкой входа; legacy-ассеты сохранены только как
неактивный резерв до отдельного решения об их удалении.

**Готово:** рабочий локальный учебный цикл, живой AI-диалог, сохранение прогресса, серверный roadmap и повторение завершенных тем.

**Ближайший результат:** регрессионная проверка нативного React-интерфейса и аккуратная очистка неиспользуемого legacy-кода.

### Статусы

- ✅ выполнено;
- 🔄 в работе;
- ⏳ запланировано.

Сначала создается рабочий учебный цикл для одного локального пользователя. Регистрация, JWT и облачная многопользовательская инфраструктура добавляются позже.

а новые предметы подключаются через данные и адаптеры, а не условия по всему
коду.
