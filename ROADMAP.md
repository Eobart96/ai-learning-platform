# Roadmap

- [x] Один канонический интерактивный Slovak A1 на `/`.
- [x] Data-driven структура 8 модулей и 83 уроков.
- [x] SQLite-состояние Module 1, практика, чтение, словарь и домашние задания.

## Ближайшие задачи

1. Восстановить зависимости и повторить полный backend/frontend test matrix.
2. Провести ручную приёмку `/` в светлой/тёмной теме и узком окне.
3. Проверить качество и глубину Modules 2–8 относительно эталонного Module 1.
4. Получить актуальный dependency/security audit без автоматического `fix`.
5. Опубликовать проверенное compact-дерево в существующую ветку GitHub `main`.
