# Roadmap

## Главный принцип

Сначала создается рабочий учебный цикл для одного локального пользователя. Регистрация, JWT и облачная многопользовательская инфраструктура добавляются позже.

## Этап 0. Подготовка

- создать GitHub-репозиторий;
- добавить документацию;
- подготовить структуру проекта;
- определить MVP;
- настроить задачи GitHub Projects.

## Этап 1. Ядро обучения без регистрации

- консольный или API-прототип AI-преподавателя;
- курс словацкого A1;
- уроки и упражнения;
- проверка ответов;
- исправления и объяснения;
- SQLite;
- сохранение попыток и ошибок;
- прогресс одного локального пользователя.

## Этап 2. Домашние задания и повторение

- автоматическая генерация домашнего задания;
- проверка выполнения;
- персональный словарь;
- интервальное повторение;
- повторение слабых тем.

## Этап 3. AI-дневник

- ежедневные вопросы;
- оригинальная запись;
- исправленный вариант;
- объяснение ошибок;
- новые слова;
- недельный отчет.

## Этап 4. Web-интерфейс

- Next.js;
- список курсов;
- страница урока;
- AI-чат;
- прогресс;
- ошибки;
- словарь;
- домашние задания;
- дневник;
- мобильная адаптация.

## Этап 5. Регистрация и вход

Добавляется только после рабочего учебного цикла:

- модель User;
- регистрация;
- вход;
- JWT;
- личный кабинет;
- разделение данных пользователей;
- восстановление доступа.

## Этап 6. PostgreSQL и production

- миграция с SQLite;
- облачная PostgreSQL;
- Docker;
- CI/CD;
- мониторинг;
- резервное копирование;
- production deployment.

## Этап 7. Конструктор курсов

- полноценный формат YAML/JSON;
- новые типы упражнений;
- настройки AI по предметам;
- импорт курсов без изменения ядра.

## Этап 8. Второй предмет

- Python для начинающих или математика для поступления.

## Этап 9. Голос и Telegram

- речь в текст;
- озвучивание;
- голосовые упражнения;
- Telegram-клиент;
- напоминания.
