# Roadmap

## Текущее состояние — 2026-08-27

- [x] Один канонический интерактивный Slovak A1 на `/`.
- [x] Data-driven структура 8 модулей и 83 уроков.
- [x] SQLite-состояние Module 1, практика, чтение, словарь и домашние задания.
- [x] Структурированный AI-чат и локальный Codex/OpenAI-compatible provider.
- [x] Windows launcher, repository audit и компактная документация.
- [x] Старый classic-контур вынесен из public-ready дерева.
- [x] Настройки AI-provider: Codex CLI, OpenAI API и Polza API.
- [x] Compact runtime опубликован в `origin/main`; GitHub CI прошёл.
- [x] Полная локальная test matrix повторена после публикации.
- [x] Module 2 расширен до подробного формата Module 1: 7 уроков, 3
  тематические группы, пошаговые практики, проверки и сохранение прогресса.

## Ближайшие задачи

1. Отозвать прежний provider credential, след которого подтверждён в
   Git-истории, и записать только факт отзыва без значения секрета.
2. Подготовить отдельное обновление зависимостей: `npm audit` сообщает 6 high
   advisories, а полный автоматический fix предлагает breaking-переход на
   Next.js 16.
3. Провести ручную приёмку `/` с реальным AI-provider в светлой/тёмной теме и
   узком окне.
4. Расширить Module 3 до формата Modules 1–2, сохранив его утверждённые slug и
   границы Slovak A1.
5. Затем последовательно проверить и расширить Modules 4–8.

- миграции БД, multi-user/auth и production deployment;
- синхронизация между устройствами.
