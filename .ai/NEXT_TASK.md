## Задача

Реализовать первый вертикальный срез учебного цикла: получение урока и его упражнений через API.

## Нужно реализовать

1. Добавить `GET /api/v1/courses/{course_slug}`.
2. Добавить `GET /api/v1/lessons/{lesson_id}`.
3. Возвращать урок, теорию и упражнения в стабильной JSON-структуре.
4. Добавить обработку `404` для неизвестного курса и урока.
5. Добавить API-тесты для успешного получения и ошибок `404`.

## Ограничения

- не добавлять регистрацию;
- не добавлять JWT;
- не подключать PostgreSQL;
- не создавать frontend;
- не вызывать OpenAI API в этой задаче;
- не добавлять отправку и проверку ответов до готовности API чтения урока.

## Критерии готовности

- курс доступен по slug;
- урок доступен по id;
- вложенные упражнения возвращаются в ответе;
- неизвестные ресурсы дают `404`;
- тесты проходят;
- `CURRENT_STATE.md` обновлен.
