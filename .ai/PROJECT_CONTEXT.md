# Project Context for Codex

## Project

AI Learning Platform — универсальная образовательная платформа с AI-преподавателем.

Первый рабочий курс: словацкий язык A1 для русскоговорящего пользователя.

## Главная цель MVP

Создать полный учебный цикл для одного локального пользователя без регистрации:

1. открыть урок;
2. выполнить задание;
3. получить исправление и объяснение;
4. сохранить ответ и ошибку;
5. обновить прогресс;
6. получить домашнее задание;
7. повторить слабую тему позже.

## Не входит в ранний MVP

- регистрация и вход;
- JWT;
- платежи;
- роли администратора и преподавателя;
- социальные функции;
- мобильное приложение;
- микросервисная архитектура.

## Стек

Backend:
- Python;
- FastAPI;
- SQLAlchemy;
- Alembic;
- SQLite на раннем MVP;
- PostgreSQL после появления нескольких пользователей;
- Pydantic;
- OpenAI API.

Frontend:
- Next.js;
- React;
- TypeScript;
- Tailwind CSS.

Infrastructure:
- Docker позже;
- GitHub Actions позже;
- Vercel для frontend;
- Railway, Render или Fly.io для backend.

## Ключевые принципы

- сначала рабочая учебная логика, затем инфраструктура;
- один модульный монолит для MVP;
- курсы хранятся как данные, а не жестко в коде;
- ответы AI для приложения должны быть структурированными и валидироваться Pydantic;
- каждое изменение базы оформляется миграцией после подключения Alembic;
- секреты никогда не коммитятся;
- важные решения фиксируются в DECISIONS.md;
- после выполнения задачи обновляются CURRENT_STATE.md и NEXT_TASK.md.

## Перед началом работы

Codex должен прочитать:

1. `.ai/PROJECT_CONTEXT.md`;
2. `.ai/CURRENT_STATE.md`;
3. `.ai/NEXT_TASK.md`;
4. `.ai/CONVENTIONS.md`;
5. документы из `docs/`, связанные с задачей.
