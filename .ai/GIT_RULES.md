\# GIT\_RULES.md



\## Назначение



Этот документ определяет, какие файлы разрешено добавлять в Git, а какие запрещено коммитить.



Все AI-агенты (Codex, ChatGPT, Claude Code и другие) обязаны соблюдать эти правила.



\---



\# Общий принцип



В Git попадает только то, что необходимо для:



\- разработки;

\- запуска проекта;

\- документации;

\- совместной работы.



В Git \*\*никогда\*\* не попадают секреты, личные данные пользователей и временные файлы.

\# Запрещено коммитить



\## Секреты



Никогда не коммитить:



\- .env

\- .env.local

\- .env.production

\- \*.pem

\- \*.key

\- service-account.json

\- credentials.json



Также запрещено коммитить:



\- OpenAI API Key

\- JWT Secret

\- OAuth Token

\- Database Password

\- Supabase Secret

\- Любые приватные ключи



\---



\## Пользовательские данные



Запрещено коммитить реальные:



\- дневники;

\- домашние задания;

\- переписки;

\- сообщения пользователей;

\- экспортированные данные;

\- резервные копии.



\---



\## Базы данных



Не коммитить:



\- \*.db

\- \*.sqlite

\- \*.sqlite3



Исключение — специально подготовленная тестовая база без пользовательских данных.



\---



\## Временные файлы



Не коммитить:



\- \_\_pycache\_\_/

\- .pytest\_cache/

\- .mypy\_cache/

\- node\_modules/

\- dist/

\- build/

\- .next/

\- logs/

\- \*.log



\---



\## Временные AI-файлы



Не коммитить:



\- .ai/tmp/

\- .ai/chat\_history.md

\- .ai/debug.md

\- .ai/token\_usage.json

\- любые автоматически созданные временные файлы.



\---



\# Правила для AI



Перед началом работы AI обязан:



1\. Прочитать PROJECT\_CONTEXT.md.

2\. Прочитать CURRENT\_STATE.md.

3\. Прочитать NEXT\_TASK.md.

4\. Следовать DECISIONS.md и CONVENTIONS.md.

5\. Не нарушать архитектуру проекта без необходимости.



После завершения задачи AI обязан:



1\. Обновить CURRENT\_STATE.md.

2\. Обновить NEXT\_TASK.md.

3\. При необходимости обновить DECISIONS.md.

4\. Проверить, что секреты не добавлены в Git.

5\. Не изменять документацию без причины.



\---



\# Перед каждым коммитом



AI должен проверить:



\- нет ли секретов;

\- нет ли пользовательских данных;

\- нет ли временных файлов;

\- обновлена ли документация;

\- проходит ли проект сборку (если применимо).



Если есть сомнения, файл \*\*не должен\*\* попадать в Git до подтверждения разработчиком.



\---



\# Главное правило



Если файл содержит секреты, персональные данные или является временным артефактом — \*\*не коммитить\*\*.



Если файл помогает понимать, запускать, развивать или документировать проект — \*\*коммитить\*\*.
