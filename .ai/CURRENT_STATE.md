# Current State

Последнее обновление: 2026-07-21.

## Текущий статус

Проект находится на этапе реализации минимального backend-прототипа MVP.

## Уже подготовлено

- описание продукта;
- roadmap;
- архитектурное описание;
- предварительная схема базы данных;
- предварительное API;
- описание AI-системы;
- формат курса;
- пример курса Slovak A1;
- первый системный промпт преподавателя;
- шаблоны GitHub Issues и Pull Request;
- FastAPI-приложение с GET /health;
- конфигурация через переменные окружения;
- SQLite с автоматическим созданием файла базы;
- SQLAlchemy-модели курса, модулей, уроков, упражнений, попыток, ответов и ошибок;
- идемпотентная загрузка course-content/slovak-a1/course.yaml;
- endpoint GET /api/v1/courses;
- два API-теста;
- точные инструкции локального запуска в README.

## Еще не реализовано

- обработка учебных ответов;
- рабочий API учебного цикла;
- AI-клиент;
- проверка ответа;
- сохранение прогресса;
- frontend;
- расширенные тесты учебного цикла;
- развертывание.

Известные ограничения текущей реализации:

- загрузчик пока импортирует курс только при старте приложения;
- API пока предоставляет только health-check и список курсов;
- нет Alembic-миграций, используется Base.metadata.create_all;
- AI, проверка ответов, frontend, регистрация и пользовательские данные еще не реализованы.

## Принятое изменение MVP

Регистрация и авторизация перенесены на более поздний этап. Ранний MVP работает для одного локального пользователя.

## Обязанность Codex после изменений

После каждой завершенной задачи:

- обновить разделы этого файла;
- отметить, что реализовано;
- указать известные ограничения;
- записать следующую конкретную задачу в `NEXT_TASK.md`;
- не отмечать задачу выполненной, если тесты не проходят.
