## Еще не реализовано

- ручная приемка полного учебного цикла в браузере;
- развертывание.

Известные ограничения текущей реализации:

- загрузчик пока импортирует курс только при старте приложения;
- API пока предоставляет health-check, курсы, уроки, ответы, прогресс, домашние задания и диалог;
- нет Alembic-миграций, используется Base.metadata.create_all;
- домашнее задание можно отправить из UI, проверить через AI и сохранить результат в SQLite;
- новые слова из AI-ответов сохраняются в SQLite и отображаются в UI для повторения;
- основной UI перенесён в Next.js: он проксирует API FastAPI и содержит
  совместимый слой для сохранения работающего учебного интерфейса;
- доступна светлая и графитовая тёмная тема с фиолетовым акцентом; выбранная тема
  сохраняется локально в браузере;
- начат поэтапный перенос legacy-интерфейса в React: оболочка приложения,
  брендированная шапка и переключатель темы реализованы нативными компонентами Next.js;
- две панели объединены в единую React-шапку: в неё перенесены навигация,
  статус Codex, состояние синхронизации, ссылка API и сброс прогресса;
- повышена читаемость интерфейса: увеличены размеры служебного и учебного текста,
  рабочие разделы занимают доступную ширину, iframe подстраивается под содержимое
  и не создаёт второй вертикальный скролл;
- типографика переведена на системный Segoe UI Variable Text: основной учебный
  текст увеличен, межстрочные интервалы расширены, избыточная жирность уменьшена;
- развёрнутый диалог ограничен высотой окна: длинные сообщения и история
  прокручиваются внутри своих областей, а форма ответа остаётся доступной;
- кнопка «Закончить тему (тест)» предназначена для проверки сценария и пропускает практику;
- реальный Codex-запрос требует локального codex login и доступа к ChatGPT backend;
- установщик требует предварительно установленный Python 3.12+; установку самого Python он не выполняет;
- полноценное облачное развертывание, регистрация и пользовательские данные еще не реализованы; frontend остаётся локальным MVP, а legacy-слой пока не разделён на React-компоненты.
- теория пока хранится в YAML и импортируется при старте приложения; для редактирования курса без перезапуска нужна отдельная админка или hot-reload.
- профиль, учебный roadmap и методика теперь берутся из обновленных пользовательских MD-файлов при каждом запросе AI-контекста.
