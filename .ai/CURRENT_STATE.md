## Текущий статус

### Checkpoint 2026-08-12 — упражнения и ошибки

- В словацком разделе «Упражнения» добавлен контекстный AI-чат справа:
  получает текущую тему, выбранное упражнение, черновик ответа и не более шести
  последних реплик. До попытки ученика он объясняет правило и следующий шаг,
  а не выдаёт полный готовый ответ. На телефоне панель открывается кнопкой.
- Рабочая область упражнений расширена до трёх читаемых колонок; чат растянут
  по высоте формы ответа и не опускает поле ввода к нижнему краю без причины.
- В разделе «Ошибки» добавлено подтверждаемое действие «Исправить всё». Оно
  закрывает только активные ошибки выбранного курса, не смешивая словацкий и
  математический списки.
- Подтверждено в этом checkpoint: `backend/.venv/Scripts/python.exe -m pytest tests -q`
  — 62 passed, 1 warning; `compileall -q app` и `npx.cmd tsc --noEmit --incremental false`
  завершились успешно; `git diff --check` не сообщил ошибок пробелов.
- Не подтверждено: `npm.cmd run build` завис после стартовой строки Next.js
  более чем на 90 секунд и был остановлен. Не считать production build успешным
  до отдельной диагностики без работающего dev-сервера.

Проект находится на этапе стабилизации локального учебного MVP: backend, живой AI-диалог и основной frontend работают вместе. На сегодня основной учебный цикл и интерфейсные функции завершены.

Начат этап подготовки к open source и гибкому модульному монолиту. Публикация
на GitHub не выполняется, пока владелец не примет отдельное решение.

В React нативно перенесены шапка, упражнения, тесты, ошибки, словарь, AI-дневник, домашние задания, живой чат и roadmap. Совместимый iframe больше не используется в рабочем интерфейсе; legacy-ассеты сохранены как обратимый резервный путь.

В Python-курсе начат перенос первоисточников: глава 1 и задания 1.1–1.4 из
`Python/python manual part 1.pdf` и `Python/python tasks part 1.pdf` добавлены
с отдельными стартовым кодом, подсказкой, необязательным разбором и сценариями
ввода/ожидаемого вывода. Сценарии исполняются только в Pyodide в браузере;
сервер не запускает код ученика.
Все семь тем первой части теперь расширены по `python manual part 1.pdf`:
переменные и типы, ввод, условия, циклы, списки и функции содержат исходные
правила, примеры и ограничения, а не общие краткие описания.
Из `python tasks part 1.pdf` перенесены задания 2.1–2.4 и 3.1–3.4: у каждого
есть стартовый код, подсказка, необязательный разбор и сценарии проверки.
Ожидаемый вывод сценариев учитывает поведение Pyodide: введённое значение не
дублируется в захваченном выводе, поэтому его не ошибочно требуют от ученика.
Завершение Python-темы также локальное: после успешного запуска хотя бы одного
упражнения пользователь переходит к следующей теме, а отметка хранится в
`localStorage`. Серверный endpoint завершения урока для Python не вызывается.

## Еще не реализовано

- ручная приемка полного учебного цикла в браузере;
- развертывание.

Известные ограничения текущей реализации:

- загрузчик пока импортирует курс только при старте приложения;
- API пока предоставляет health-check, курсы, уроки, ответы, прогресс, домашние задания и диалог;
- нет Alembic-миграций, используется Base.metadata.create_all;
- домашнее задание можно отправить из UI, проверить через AI и сохранить результат в SQLite;
- новые слова из AI-ответов сохраняются в SQLite и отображаются в UI для повторения;
- основной UI перенесён в Next.js и нативные React-компоненты; он проксирует
  API FastAPI;
- доступна светлая и графитовая тёмная тема с фиолетовым акцентом; выбранная тема
  сохраняется локально в браузере;
- React-перенос всех рабочих экранов завершён; совместимый iframe не
  используется. `frontend/public/legacy` остаётся обратимым резервным путём
  до отдельного решения об удалении;
- две панели объединены в единую React-шапку: в неё перенесены навигация,
  статус Codex, состояние синхронизации, ссылка API и сброс прогресса;
- повышена читаемость интерфейса: увеличены размеры служебного и учебного
  текста, а Markdown преподавателя отображается структурированно;
- типографика переведена на системный Segoe UI Variable Text: основной учебный
  текст увеличен, межстрочные интервалы расширены, избыточная жирность уменьшена;
- развёрнутый диалог ограничен высотой окна: длинные сообщения и история
  прокручиваются внутри своих областей, а форма ответа остаётся доступной;
- кнопка «Закончить тему (тест)» предназначена для проверки сценария и пропускает практику;
- реальный Codex-запрос требует локального codex login и доступа к ChatGPT backend;
- установщик требует предварительно установленный Python 3.12+; установку самого Python он не выполняет;
- полноценное облачное развертывание, регистрация и пользовательские данные еще не реализованы; frontend остаётся локальным MVP.
- теория пока хранится в YAML и импортируется при старте приложения; для редактирования курса без перезапуска нужна отдельная админка или hot-reload.
- профиль, учебный roadmap и методика теперь берутся из обновленных пользовательских MD-файлов при каждом запросе AI-контекста.
- AI-диалог, дневник, словарь и домашние задания пока остаются
  языко-ориентированными и не используются математическим модулем.

## Принятое изменение MVP

Регистрация и авторизация перенесены на более поздний этап. Ранний MVP работает для одного локального пользователя.

## Обязанность Codex после изменений

После каждой завершенной задачи:

- обновить разделы этого файла;
- отметить, что реализовано;
- указать известные ограничения;
- записать следующую конкретную задачу в `NEXT_TASK.md`;
- не отмечать задачу выполненной, если тесты не проходят.
