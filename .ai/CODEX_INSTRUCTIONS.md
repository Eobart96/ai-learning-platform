# Instructions for Codex

## Рабочий процесс

1. Прочитай `.ai/PROJECT_CONTEXT.md`.
2. Прочитай `.ai/CURRENT_STATE.md`.
3. Прочитай `.ai/NEXT_TASK.md`.
4. Прочитай `.ai/CONVENTIONS.md`.
5. Изучи только те документы из `docs/`, которые относятся к текущей задаче.
6. Перед изменениями кратко перечисли затрагиваемые файлы.
7. Реализуй только текущую задачу.
8. Запусти тесты и проверки.
9. Исправь обнаруженные ошибки.
10. Обнови `.ai/CURRENT_STATE.md` и `.ai/NEXT_TASK.md`.

## Запрещено

- самовольно добавлять функции следующего этапа;
- добавлять регистрацию в ранний MVP;
- заменять рабочий код псевдокодом;
- удалять тесты ради успешного запуска;
- менять стек без обоснования;
- хранить секреты в репозитории;
- утверждать, что задача готова, если проверки не запускались.

## Формат итогового отчета

- что изменено;
- какие файлы созданы или изменены;
- какие команды проверки запущены;
- результаты тестов;
- известные ограничения;
- следующая задача.
