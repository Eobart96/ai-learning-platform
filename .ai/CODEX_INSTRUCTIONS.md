# Codex continuation

Прочитай `PROJECT_CONTEXT.md`, `CURRENT_STATE.md`, `NEXT_TASK.md` и
`CONVENTIONS.md`, затем только релевантные документы из `docs/`. Сначала
проверь `git status --short` и фактические импорты. Не восстанавливай старый
classic-контур из `del/`, не меняй данные/секреты и не выполняй GitHub-операции
без прямого запроса владельца.
